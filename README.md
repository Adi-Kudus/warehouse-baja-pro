# Analisa Struktur Baja Warehouse Pro v2.0

Aplikasi profesional analisa & desain struktur baja gudang/workshop — versi penuh.

## Modul
1. **Analisa Struktur Baja** — gudang baja SNI 1726:2019, SNI 1727:2020, SNI 1729:2020, SNI 2847:2019, SNI 8460:2017
2. **Analisis Pondasi** — pondasi telapak & tiang pancang
3. **Pustaka Profil Baja** — 334 profil, 3 standar: BS 4-1:2005 (UB/UC/PFC), EN 10365 (IPE/HEA/HEB/HEM/UPN/UPE), JIS G 3192/3350 (HW/HM/HN/I/UNP/CNP)
